Park Accessibility in Lexington, Kentucky

A static map showing estimated walking access to public parks in Lexington.

Project Description

This project examines park accessibility in Lexington, Kentucky by showing areas within estimated walking distances of public parks. The map uses distance-based access zones to highlight areas with stronger access to green space and areas that may be less well served.

Final Map

The map below shows estimated 5- and 10-minute walking access zones around public parks in Lexington.

Map Metadata

Author: Ishrat Jahan

Location: Lexington, Kentucky

Software Used: QGIS

Map Type: Static map exported as JPG

Projection: NAD 83/ Kentucky Single Zone

Data Layers: Parks and streets

Method: Park accessibility was estimated using distance buffers around public parks. These buffers represent approximate walking access zones.
